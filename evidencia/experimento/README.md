# Corrida oficial del experimento A/B/C

Resultados de `patchlayer experimento` sobre el corpus completo (#13). Solo se regeneran a propósito, cuando cambia el corpus o la compuerta:

```
uv run patchlayer experimento --salida evidencia/experimento
```

Una corrida sin `--salida` escribe en `resultados/`, que git ignora.
